# Changelog — 0.4.0

## BehaviorTree — Shared-tree rewrite (breaking)

`BTree` is a new implementation. One tree is built once and shared by every agent; agents are integer slots, and per-agent state lives in Struct-of-Maps tables inside the nodes. Measured in Roblox Studio on the same trees: 10–30x less time per agent per tick, zero garbage per tick (was 224–1120 bytes), about 30x less memory per agent, and agent creation 50–80x cheaper. Full documentation: [behavior-tree.md](../behavior-tree.md); migration table at the end of it.

### API changes

- **Nodes are factories, not classes.** `new BTree.Sequence().AddChild(a)` becomes `BTree.Sequence(a, b)`. Decorators take parameters first and the child last: `BTree.Timeout(10, child)`, `BTree.Cooldown(2, child)`, `BTree.Repeat(3, child)`. Subclassing `BTree.Node` is replaced by a factory returning `{ Name, Tick, Halt, Maps }`.
- **One tree, many agents.** `new BTree.BehaviorTree(root)` once; `tree.AddAgent()` per agent (returns a slot); `tree.Tick(dt)` ticks every agent; `tree.GetStatus(slot)`; `tree.RemoveAgent(slot)`; `tree.Halt(slot)` / `tree.HaltAll()`; `tree.TickAgent(slot, dt)` for drivers with their own loop.
- **ECS ids.** `new BTree.BehaviorTree(root, { external_ids: true })` makes `AddAgent(entity)` use your entity id as the slot; duplicates throw and the tree never recycles your ids.
- **Callbacks receive `(slot, dt, tree)`** instead of `(bb, dt)`.
- **No `Blackboard` inside the tree.** Per-agent data is a `Map<Slot, T>` per field: `tree.Field<T>(cleanup?)` creates one, `tree.RegisterField(map, cleanup?)` adopts one. Registered fields are cleared when an agent is removed; `cleanup(slot, value)` runs first for agents that had a value. `tree.OnAgentRemoved(cb)` runs before field cleanup with all fields still readable. `Blackboard` itself is unchanged and still exported for the FSM.
- **Lifecycle.** `OnBecameActivated` / `OnBecameInactive` are removed. `Leaf({ OnStart?, OnTick, OnHalt?, OnSuccess?, OnFailure?, OnExit?, OnEnter?, OnLeave? })` replaces `FullAction`; hooks are resolved at build time so absent hooks cost nothing. `OnEnter` / `OnLeave` bracket the span in which the leaf is visited (across runs).
- **New nodes.** `Scope({ OnEnter, OnExit })` brackets the visited span of a branch; `Scoped(config, child)` does the same around a subtree.
- **Changed nodes.** `Switch(selector, cases, default?)` takes a selector function and a `Map`; `Timer(field)` and `WasFieldUpdated([fields], skip_first)` (was `WasEntryUpdated`) take fields; `FSMConnector(getFsm)` and `GoapConnector(getAgent)` take per-slot getters. `SubTree` is removed: any node can be used directly as a subtree, but never at two positions of one tree.
- **Removed:** `Node.IsRunning()`, `GetActiveNodes()`, `CreateFullAction`.

### Semantics kept

Every composite and decorator behaves as in 0.3, verified tick by tick against the previous implementation (4 scenario trees plus one exercising the whole catalogue, 80 ticks each with agent add/remove/id reuse). One exception is by design: halting now cascades along the running path instead of being diffed from sets, so `OnHalt` fires in the same tick the parent stops ticking a child.

## FSM / GOAP connectors

`FSM.BehaviorTreeConnector(tree, slot)` and `Goap.BTConnector(tree, slot)` now take the shared tree and the entity's slot, tick that one agent, and halt it on exit.

## BTCreator

- `Build()` no longer takes a blackboard and returns a shared tree; `BuildRoot()` returns the root node only (for embedding).
- `new BTCreator({ external_ids: true })` forwards tree options.
- Registered actions / conditions / callbacks receive `(slot, dt, tree)`.
- New `RegisterField(name, map?)`: fields the JSON refers to by name (`Timer.timerName`, `WasEntryUpdated.entries`, `Switch.parameter_name`); they are attached to the built tree. New `RegisterSelector(name, fn)` for `Switch` nodes keyed by something other than a field. `RegisterSubTree(name, () => Node)` now returns a root node.
- New node kinds in the v2 schema: `Scope` (`onEnter`, `onExit` callback names), `Log`, `ForceRunning`, `TryCatch`, `WasEntryUpdated` were already loadable and are now listed in the docs.
- Helpers for custom creators: `GetCurrentChildren()`, `GetCurrentChild()`, `GetCurrentNodeOptionalString(name)`, `GetField(name)`. `GetCurrentBlackboard()` is removed.

## Tooling

`luau-bench/` (not published) holds the design experiments behind this release: a Lune harness with a differential test against the 0.3 tree, six candidate implementations with reports, micro-benchmarks, and a runner that executes the same bench inside Roblox Studio through the Studio MCP server in both codegen modes.
